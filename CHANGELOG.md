
# Changelog

All notable changes to CryptX are documented here.

## [2.0.0] 

### Added

- Added directory encryption support.
- Added directory decryption support.
- Improved error handling.

## [1.5.0] 

### Added

- File Encryption: Added support for encrypting files directly from the command line.
- File Decryption: Added functionality to decrypt files encrypted with CryptX.
- AES-256-GCM: Implemented authenticated encryption for data confidentiality and integrity.
- PBKDF2 Key Derivation: Added passphrase-based encryption key derivation.
- Custom File Extension: Introduced the .crypenc extension for encrypted files generated by CryptX.

## [1.0.0] 

### Added
- Initial encryption method.
- Initial decryption method.
- Custom terminal banner.
- Command-line usage for encryption and decryption.
